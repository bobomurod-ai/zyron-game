# 🚀 ZYRON - 2D Kosmik Jang va Sarguzasht O'yini

**ZYRON** — bu to'liq funksional, zamonaviy HTML5 Canvas va Web Audio API texnologiyalariga asoslangan kosmik 2D jangovar sarguzasht o'yini.

---

   - Ekran tebranishi (Screen Shake), zarba chaqnashlari, suzuvchi raqamli zararlar va kritik zarbalar.

2. **🗺️ Xarita (Turli xil sayyoralarni tanlash)**:

## 🕹️ O'yinni Qanday Ishga Tushirish Mumkin?

O'yin hech qanday tashqi kutubxona yoki server o'rnatishni talab qilmaydi:
1. `index.html` faylini istalgan brauzerda (Chrome, Edge, Firefox, Safari) ochish kifoya!
2. Yoki Python orqali mahalliy serverda ishga tushirish:
   ```bash
   python -m http.server 8000
   ```
   So'ngra brauzerda `http://localhost:8000` manziliga kiring.
